# 率土战局（stzb-warroom）

《率土之滨》的第三方游戏助手，在电脑上运行。玩游戏时开着它，助手就能看懂你这边的战局：敌军打过来时告诉你来的是什么队、
几点到；在游戏里点开一个地方，告诉你那里有哪些敌军、派哪队去接。手机上也能收到推送。

**官网：** <https://stzb.nzery.dev>（介绍、下载和使用说明）

**致游戏官方：** 这是个人业余、非商业的项目，希望其中发现的协议问题能为官方优化提供参考。官方如果觉得不妥，
请发邮件到 <admin@nzery.dev>，我会马上关闭相关服务器，并取消项目的公开状态。

**看看效果：** [战局网站演示](https://stzb.nzery.dev/43lBbwxrX3FKQjVsu8xD9NeSickoGNKjbOUFao5NwxA/)，这里是几个服务器的历史数据，不再更新。加入后从助手打开自己的链接，看到的才是最新战况。

## 能收到哪些通知

目前只做两类敌情通知，外加一个同步战报的提醒：

| 通知 | 什么时候 |
|---|---|
| 敌袭 | 游戏里出现敌袭预警、敌军打的是你的地块时 |
| 查看 | 你在游戏里点开一个地方：正打那里、驻守在那里、正去那里驻守或调兵、从那里出发还在路上的敌军，各列一张表 |
| 同步 | 你的同盟在本域的同盟战报不到 2000 场时，每天一次，提醒你去同步（见下面“开始使用”第 9 步） |

下面是 2026-10-20 凌晨一次真实的“查看”通知：点开被打的要塞，同一名敌方玩家三队齐出（玩家名已隐去）：

```
查看  你的要塞 (643,443)：来袭 3 支，最早 01:11:39 到
到达      阵容                 玩家    推荐    来源      最近兵力
01:11:39  曹纯/张辽/文鸯 11红  某某甲  黄月英  战报21次  1.8万 10-18 20:21
01:11:42  曹彰/关羽/徐晃 11红  某某甲  荀彧    战报62次  1.3万 10-18 20:19
01:12:57  庞统/程昱/刘备 10红  某某甲  关银屏  战报57次  2.7万 10-19 20:45
```

手机横幅（一行一支敌军）：

```
某某甲 曹纯/张辽/文鸯 11红，推荐黄月英队
某某甲 曹彰/关羽/徐晃 11红，推荐荀彧队
某某甲 庞统/程昱/刘备 10红，推荐关银屏队
```

- **来的是哪队**：从本域大家上传的战报里认。这名玩家用过兵种相符的阵容，就直接给出阵容和红度（“来源”写见过几次）；
  认不出时写“新队伍”，三个兵种都进阶过的，再按其他玩家同兵种最常用的阵容推测（阵容后写“推测”，来源写“同兵种90%”这样的比例）。
- **派谁去接**（只在“查看”通知里）：从你进阶过的部队里，推荐本赛季打这种阵容交换比最高、且大于 1 的一队（写大营武将），
  没有就写“无”；赶不赶得到、兵力和体力由你自己判断。敌袭通知不做推荐。
- **最近兵力**：这支敌军最近一场战报打完剩下的兵力加伤兵，和那场的时间。
- 同一个地方再点开，只有部队变了才推到手机。
- 本域的战报越多，阵容识别和推荐就越准。

窗口里按 紧急 / 提醒 / 消息 分类，紧急通知会响铃。
打开列表上方的“桌面弹窗”后，手机上收到的通知也会从屏幕顶部弹出，内容和手机一样，5 秒后自动消失；窗口关掉也会弹，点一下打开通知列表，往上划可以提前关掉。全屏游戏最好用窗口化或无边框模式，独占全屏时弹窗可能盖不上去。
点列表上方的“置顶小窗”，会单独开一个只放通知的小窗口，一直显示在游戏上面，方便边打边看；拖动、拉大小和普通窗口一样，下次打开还在原来的位置。
通知表格里阵容前面有 ▸ 的队伍，点一下这一行会在下面展开这队的武将、兵种、等级、红度和战法，再点一下收起；主窗口和置顶小窗都可以。
到达时间实时倒数；通知过时了会自己清掉（比如敌袭在敌军到达或撤回时），窗口列表和手机推送都一样。

想少收一些？在窗口的**提醒**页里自己定，每一项都有一句说明，对这台电脑上的所有账号生效：

- **提醒方式**：被动（敌袭和点开地块都提醒），或主动（只在你点开地块时提醒，敌袭不提醒）。
- **点开地块时提醒**（默认开）。
- **过滤斯巴达队伍**（默认关）：每名武将只带 100 兵左右的占位队伍不提醒。
- **过滤拆迁队伍**（默认关）：兵种都没进阶、兵力超过 300 的拆迁队伍不提醒。
- **推送哪些**：全部（默认）/ 要紧的（进阶主力的敌袭、点开地块认出阵容的）/ 不推送。

窗口里还能查玩家：

- **玩家信息**：输入玩家名字（可以只输一部分），同名或名字相近的有好几个时选一个。先列出他的同盟和主城坐标，
  再列出他每支队伍最近一次的武将、等级、红度、兵种和战法（只列兵种进阶过的队伍），我方、敌方都能查。
  只能查到本赛季同盟战报和你看过的部队详情里出现过的玩家；主城坐标要镜头在地图上见过这名玩家才知道。

还能和其他玩家聊天：

- **群聊**：所有开着率土战局的人在同一个群里，左侧点“群聊”就能发消息。每个人有一个固定的随机名字（比如“沉稳的赤兔”），
  看不出是谁。程序没开的时候别人发的消息，下次打开会补上（最近一周、最多 200 条）。账号审核通过后才能用。
  一台电脑加了几个账号时，群聊页右上角可以选用哪个账号聊，各账号的消息分开显示。
  发错了可以撤回：自己的消息发出 10 分钟内，鼠标移到消息上点“撤回”，图片会从服务器和大家的电脑上删掉。
  可以发动图（GIF 等，最多 2 MB）。管理员 @ 你时会推送到手机，点开能在手机网页上聊；其他成员 @ 你也想收到推送，在群聊页勾选。

另外还有**战局网站**，在浏览器或手机上查看整个同盟的战报、阵容对局和攻城记录。

## 开始使用（Windows）

谁都可以用下面的公共域邀请码加入（私有域名额已满，暂停申请）：

```
stj_6_P0QPrwxPEFsXNapoHCMA
```

1. 先[下载 Wireshark](https://stzb.nzery.dev/download/Wireshark-x64.exe)（用 Edge 或 Chrome 浏览器直接点击下载；360、QQ 等浏览器和迅雷、IDM 等下载工具会下载失败）并安装，安装时保持勾选 Npcap，装完重启一次电脑。
2. 从 [Releases](https://github.com/nzery/stzb-warroom/releases/latest) 下载 `stzb-warroom-windows.zip`，解压到一个固定的文件夹。
3. 双击 `stzb-warroom.exe`，打开“率土战局”窗口。
4. 在“账号”里粘贴邀请码（私有域用同盟发的 `stj_` 邀请码或管理员给的 `sta_` Token），点“添加”；加入公共域也可以不粘贴，直接点“一键生成账号”。在这台电脑上玩几个游戏账号，就加几次（一次加一个，加好后先登录那个账号）。
5. 打开本程序、添加好账号之后再登录游戏，角色认领成功后自动开始，“概览”里显示“正在上报”、右上角“最近上传”有时间就说明一切正常。
6. 账号下面会出现“战局网站”，点“打开”就能在浏览器里看战局，也可以“复制链接”发到手机上打开。
7. 想在手机上收到推送：
   绑定都在窗口左侧的 **手机** 页（选好 iPhone 或安卓，第一步）：
   - iPhone：安装 Bark，把 Bark 里的地址粘贴进去，点“绑定”，收到测试通知就成功了。
   - 安卓：安装 ntfy（F-Droid 或 Google Play），点“绑定安卓”，用 ntfy App 扫出现的二维码订阅，不要用浏览器、微信或相机扫。找不到扫码入口时，在 ntfy 里点右下角 +，填助手显示的主题，勾选“使用其他服务器”并填服务器地址，再点“订阅”。回到助手点“发测试推送”。要给 ntfy 开自启动、电池设为不限制，否则锁屏后会被系统关掉。
   - 盟友没有电脑：在 **手机** 页选“盟友手机”，填盟友 Bark 里的地址（iPhone），或点“添加安卓手机”让盟友用 ntfy 订阅。你玩游戏时，推到你手机的通知也会推给他，最多 3 台。
8. 到“提醒”页按自己的需要选择要哪些通知。
9. **第一次连上后同步同盟战报**：在游戏里打开 同盟 → 同盟战报，一直往下滑到底，滑过的战报会自动上传。
   敌军阵容是从同盟战报里认的，战报太少时很多认不出；同一个同盟里有人同步过，大家都能用上。
   同盟战报不到 2000 场时，窗口和推送会提醒你，并显示已同步的场数，够了就不再提醒。

公共域谁都可以加入，不限同盟和服务器，所有成员上传的战报、阵容对局、攻城记录汇总在一起，大家都能从助手打开自己的链接查看；
敌袭等通知只发给你自己。一个角色只能被一个人认领，先到先得；加入后 3 天内没登录游戏认领，邀请就会失效，要重新添加。

窗口里还有：

- **设置**：开机自动启动、关掉窗口后继续在后台运行（默认开启）；退出程序请右键托盘图标，选择“退出”。
- **诊断**：遇到问题时点“发送给管理员”，只有管理员能看到；发不出去时再点“复制诊断信息”粘贴发给管理员。

下次打开自动开始。更详细的说明见压缩包里的 `使用说明.txt`。

## 用手机玩

手机上的游戏连接经你这台电脑出去：游戏看到的是你家里的网络，这台电脑照常上报，和在电脑上玩一样。
不用自己搭代理或 VPN，这台电脑也不开任何端口。

需要：

- 手机玩的时候，这台电脑开着、本程序在运行并且在上报。
- 账号已审核通过：先在这台电脑上登录一次游戏、认领角色（公共域也一样）。没审核通过的账号不能用手机玩。
- iPhone 上装小火箭（Shadowrocket），App Store 要用外区账号才能下载。
- 安卓上装 [v2rayNG](https://github.com/2dust/v2rayNG/releases)（免费，下载最新版 apk，一般选 `arm64-v8a`）。

窗口左侧点 **手机**，选 iPhone 还是安卓，照页面上的步骤一步一步做（每步有「上一步」「下一步」，能自动确认的步骤会打 ✓）：

- iPhone：小火箭**首页**扫「① 节点」，**“配置”页**扫「② 规则」并“使用配置”，首页“全局路由”选“配置”。
  规则只让游戏走这个节点，其他应用照常直连；在首页扫规则码会变成订阅，用不了。
- 安卓：v2rayNG 扫订阅码，更新订阅后启动，规则都在订阅里。
- 第一步先绑定手机推送（iPhone 用 Bark，安卓用 ntfy），一定要做：手机上玩时看不到电脑上的通知。
- 最后一步打开连接：小火箭点“连通性测试”或者进游戏后，页面会显示“手机已连上”；规则没生效时会标红告诉你怎么改。

出口随本程序一起运行，不用另外打开；出了问题（比如“另一台电脑正在用这个账号”）页面顶部会提示。

要注意：

- 电脑关机或本程序没运行时，游戏连不上，不会自动切回直连。先打开电脑和本程序再玩；
  安卓临时想直连玩，可在 v2rayNG 里点停止，此时不上报。
- 二维码和订阅地址就是钥匙，别发给别人：拿到的人能借你的电脑连游戏。外泄了就在扫节点（安卓是扫订阅）那一步点“换新的”，旧的 30 秒内失效，手机重新扫码。
- 这台电脑只按中转的要求连游戏服务器的 8001 端口、只连公网地址，并且只在手机发的确实是游戏数据时保持连接；
  局域网、本机、别的端口一概不连。这部分代码在 `stzb_warroom/relay.py`，可以自己看。
- 手机的游戏连接经服务器中转。中转只转发，不记录、不保存游戏内容；上报仍由这台电脑完成。

## Linux / 命令行

需要 Python 3.11+ 和 `wireshark-common`（让普通用户有权限：`sudo dpkg-reconfigure wireshark-common`，再把自己加入 `wireshark` 组）。

```sh
export ST_SERVER=https://...                 # 服务器地址找管理员要
python3 -m stzb_warroom join stj_...         # 用邀请码加入
python3 -m stzb_warroom gui                  # 和 Windows 一样的窗口；也可以用 capture（只上报）+ notify（终端里看通知）
```

窗口用 [Electron](https://www.electronjs.org/) 显示：装了 `electron` 命令（如 `npm install -g electron`），或用环境变量 `ST_ELECTRON` 指向它；都没有时在默认浏览器里打开。

开机自动运行：`deploy/client-services.sh install`，用法见脚本开头。
用手机玩（同上，账号要先审核通过）：`deploy/client-services.sh install-phone`，再按窗口“手机”页的步骤在手机上设置；
二维码和链接用 `python3 -m stzb_warroom gui` 打开窗口查看。

## 遇到问题

- 窗口顶部的红色提示条会说明问题和处理办法，按提示操作即可。
- 官网打不开、连不上服务器：多半是开着代理、VPN 或加速器，关掉它们或把 `nzery.dev` 设为直连再试。
- 电脑自己拨号上网（宽带连接）：程序会自动处理。提示抓不到当前网络时，先关掉 VPN 和加速器；还不行就改用路由器或光猫拨号。
- 加入后一直没开始：确认已经登录过游戏；提示角色已被别人认领时，发邮件给管理员核实。
- 其他问题：在“诊断”页点“发送给管理员”。
