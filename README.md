# 率土战局（stzb-warroom）

率土游戏助手的电脑客户端。玩《率土之滨》时开着它，助手就能看懂你这边的战局：敌军打过来时告诉你来的是什么队、
几点到、派哪队去接，手机上也能收到推送。

**官网：** <https://stzb.nzery.dev>（介绍、下载和使用说明）

**看看效果：** [公共域的战局网站](https://stzb.nzery.dev/43lBbwxrX3FKQjVsu8xD9NeSickoGNKjbOUFao5NwxA/)，所有公共域成员上传的战报、阵容对局和攻城记录都在这里。

## 能收到哪些通知

**敌袭**是最主要的一类。敌军行军打你的地块时，会收到这样一条（绑定了 Bark 的话，手机上同时弹出横幅）：

```
【敌袭】阮籍 / 刘伶 / 徐荣
21:35 到（还有 12 分钟）  你的要塞（612,388）
某某（某同盟）第 2 队  骑兵
应对：推荐 你的第 1 队，21:31 能赶到
```

- **来的是哪队**：这支部队在战报里出现过，就直接给出它的阵容（武将、等级、红度、战法）。
  没出现过时，按同一玩家兵种相符的部队，或者按兵种从以往战报里推测，并标明是推测。
- **派谁去接**：从你的部队里挑能赶到、体力兵力够、历史上打这种阵容换兵划算的，给出推荐顺序和赶到时间。
  正在征兵的部队会提醒先取消征兵。
- 看过的战报越多，阵容识别和推荐就越准。

其他通知：

| 通知 | 什么时候 |
|---|---|
| 盟友遇袭 | 敌军打盟友的地块，而你有部队来得及支援 |
| 领地 | 你的主城、要塞、城池被拆或失守 |
| 战斗 | 防守战斗的结果、进攻失败；打的是推荐里的第几名 |
| 阵容变化 | 某支敌军换了武将，列出原阵容和新阵容 |
| 部队 | 部队体力恢复，可以出征了 |
| 资源 | 木、铁、石、粮或政令快满仓了 |
| 同盟标记 | 同盟新增或取消标记 |
| 驻守 | 在游戏里点开一个地方，那里驻守的每支敌军和它的阵容；同一个地方只有驻守的部队变了才再通知 |
| 每日摘要 | 前一天的对战场数、胜负、交换比、敌袭次数、失守的据点 |

窗口里按 紧急 / 提醒 / 消息 分类，紧急通知会响铃，也可以弹出桌面弹窗；手机推送只发需要你马上处理的（如敌袭）。
通知过时了会自己清掉（比如敌袭在敌军到达时），窗口列表、桌面弹窗和手机推送都一样。

想少收一些？在窗口的**通知设置**里自己定，每一项下面都写了是什么意思，对这台电脑上的所有账号生效：

- **提醒方式**：被动（全部敌情都提醒），或主动（只提醒你在游戏里点开的地块）。
- **过滤斯巴达队伍**（默认开）：每名武将只带 100 兵左右的占位队伍不提醒。
- **过滤分城队伍**：从敌方分城出发的队伍不提醒。
- **盟友遇袭**：你能帮上忙时提醒 / 只在你有部队守着时提醒 / 不提醒。
- **推送到手机**：只推需要你下令的 / 所有敌情 / 不推送。
- 战斗结果、部队体力、资源、同盟标记、每日战况等可以分别关掉。
窗口里还能看你自己的部队打得怎么样（只看你自己的，不是整个同盟）：

- **我的队伍**：每支队伍现在的武将、战法、兵力、体力，这套配置和玩家打了多少场、胜负、交换比，打不过和打得过哪些敌方阵容。
  队伍按“武将 + 位置 + 战法”认，换了武将或战法就重新统计。
- **对局记录**：你的部队上场的每一场战报，可以按队伍、打玩家 / 打 NPC、胜负筛选。
- **对手分析**：和你交过手的敌方阵容，你每支队伍打它们的战绩；自己打得少时附上同盟里同样阵容对上它的战绩作参考。

另外还有**战局网站**，在浏览器或手机上查看整个同盟的战报、阵容对局和攻城记录。

## 开始使用（Windows）

谁都可以用下面的公共域邀请码加入（加入私有域见[申请自己的域](#申请自己的域)）：

```
stj_6_P0QPrwxPEFsXNapoHCMA
```

1. 先装 [Wireshark](https://www.wireshark.org/download.html)（选 “Windows x64 Installer”），安装时保持勾选 Npcap，装完重启一次电脑。
2. 从 [Releases](https://github.com/nzery/stzb-warroom/releases/latest) 下载 `stzb-warroom-windows.zip`，解压到一个固定的文件夹。
3. 双击 `stzb-warroom.exe`，打开“率土战局”窗口。
4. 在“账号与推送”里粘贴邀请码（私有域用同盟发的 `stj_` 邀请码或管理员给的 `sta_` Token），点“添加”。在这台电脑上玩几个游戏账号，就加几次（一次加一个，加好后先登录那个账号）。
5. 登录游戏，角色认领成功后自动开始，“概览”里显示“正在上报”就说明一切正常。
6. 账号下面会出现“战局网站”，点“打开”就能在浏览器里看战局，也可以“复制链接”发到手机上打开。
7. 想在 iPhone 上收到推送：安装 Bark，把 Bark 里的地址粘贴到账号下面，点“绑定”，收到测试通知就成功了。
8. 到“通知设置”里按自己的需要选择要哪些通知。
9. **第一次连上后同步同盟战报**：在游戏里打开 同盟 → 同盟战报，一直往下滑到底，滑过的战报会自动上传。
   敌军阵容是从同盟战报里认的，战报太少时只能按兵种推测，不一定准；同一个同盟里有人同步过，大家都能用上。
   同盟战报不到 2000 场时，窗口和推送会提醒你，并显示已同步的场数，够了就不再提醒。

公共域谁都可以加入，不限同盟和服务器，所有成员上传的战报、阵容对局、攻城记录汇总在一起，大家都能在战局网站上看到；
敌袭等通知只发给你自己。一个角色只能被一个人认领，先到先得；加入后 3 天内没登录游戏认领，邀请就会失效，要重新添加。

窗口里还有：

- **设置**：开机自动启动、关掉窗口后继续在后台运行（默认开启）；退出程序请右键托盘图标，选择“退出”。
- **诊断**：遇到问题时点“复制诊断信息”发给管理员。

下次打开自动开始。更详细的说明见压缩包里的 `使用说明.txt`。

## 用手机玩

手机上的游戏连接经你这台电脑出去：游戏看到的是你家里的网络，这台电脑照常上报，和在电脑上玩一样。
不用自己搭代理或 VPN，这台电脑也不开任何端口。

需要：

- 手机玩的时候，这台电脑开着、本程序在运行并且在上报。
- 账号已审核通过：先在这台电脑上登录一次游戏、认领角色（公共域也一样）。没审核通过的账号不能用手机玩。
- iPhone 上装小火箭（Shadowrocket），App Store 要用外区账号才能下载。安卓上支持 VLESS 的同类软件理论上也行，还没有测过。

步骤：

1. 窗口左侧点 **用手机玩**，打开“允许手机经本机连接游戏”。
2. 用小火箭首页左上角的扫码，扫页面上“率土战局-主节点”的二维码，添加节点。
3. 在小火箭的配置里加一条规则 `DST-PORT,8001,率土战局-主节点`，放在 `GEOIP`、`FINAL` 等规则前面。
   只让这一条走这个节点，别的流量不要走它（它只转游戏的连接，别的会连不上）。
4. 可选：再扫“率土战局-备节点”，建一个“故障转移”策略组（主节点、备节点、DIRECT），规则改指向这个组。
   电脑没开时自动直连，游戏照玩，只是不上报。
5. 登录游戏，页面上的节点显示“已连接”、出现“正在转发 1 条游戏连接”就成功了。

要注意：

- 二维码就是钥匙，别发给别人：拿到的人能借你的电脑连游戏。外泄了就在页面上点“重置”，旧的 30 秒内失效，手机重新扫码。
- 这台电脑只按中转的要求连游戏服务器的 8001 端口、只连公网地址，并且只在手机发的确实是游戏数据时保持连接；
  局域网、本机、别的端口一概不连。这部分代码在 `stzb_warroom/relay.py`，可以自己看。
- 手机的游戏连接经服务器中转。中转只转发，不记录、不保存游戏内容；上报仍由这台电脑完成。

## Linux / 命令行

需要 Python 3.11+ 和 `wireshark-common`（让普通用户有权限：`sudo dpkg-reconfigure wireshark-common`，再把自己加入 `wireshark` 组）。

```sh
export ST_SERVER=https://...                 # 服务器地址找管理员要
python3 -m stzb_warroom join stj_...         # 用邀请码加入
python3 -m stzb_warroom gui                  # 和 Windows 一样的窗口；也可以用 capture（只上报）+ notify（终端里看通知）
```

窗口用 [Electron](https://www.electronjs.org/) 显示：装了 `electron` 命令（如 `npm install -g electron`），或用环境变量 `ST_ELECTRON` 指向它；都没有时在默认浏览器里打开。

开机自动运行：`deploy/client-services.sh install`，用法见脚本开头。
用手机玩（同上，账号要先审核通过）：`deploy/client-services.sh install-phone`，再按上面第 2～5 步在手机上设置；
二维码和链接用 `python3 -m stzb_warroom gui` 打开窗口查看。

## 遇到问题

- 窗口顶部的红色提示条会说明问题和处理办法，按提示操作即可。
- 加入后一直没开始：确认已经登录过游戏；提示角色已被别人认领时，发邮件给管理员核实。
- 其他问题：把“诊断”页的诊断信息发给管理员。

## 申请自己的域

想要只有你们同盟自己看得到的私有域（还有智能问答），发邮件到 <admin@nzery.dev> 找管理员申请域账号。服务器容量有限，先到先得。
