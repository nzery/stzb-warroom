# 率土战局（stzb-warroom）

率土游戏助手的电脑客户端。玩《率土之滨》时开着它，助手就能看懂你这边的战局：敌军打过来时告诉你来的是什么队、
几点到、派哪队去接，手机上也能收到推送。

**官网：** <https://stzb.nzery.dev>（介绍、下载和使用说明）

**网络要求：** 公网服务器受到的攻击较多，服务器（`*.nzery.dev`）已屏蔽国外 IP。下载和使用时请关闭代理、VPN 和加速器
（包括全局 / TUN 模式），或在代理规则里把 `nzery.dev` 及其子域名设为直连（DIRECT）。官网下载不了时可以从本页
[Releases](https://github.com/nzery/stzb-warroom/releases/latest) 下载，但客户端使用时仍要用国内网络直连服务器。

**看看效果：** [公共域的战局网站](https://stzb.nzery.dev/43lBbwxrX3FKQjVsu8xD9NeSickoGNKjbOUFao5NwxA/)，所有公共域成员上传的战报、阵容对局和攻城记录都在这里。

## 能收到哪些通知

**敌袭**是最主要的一类。敌军行军打你的地块时，窗口里收到一条通知（绑定了手机推送的话，手机上同时弹出横幅）。
下面是 2026-10-20 凌晨一次真实的来袭（同一名敌方玩家三队齐出，玩家名已隐去）：

```
查看  你的要塞 (643,443)：来袭 3 支，最早 01:11:39 到
到达      阵容                 玩家    推荐    来源      最近兵力
01:11:39  曹纯/张辽/文鸯 11红  某某甲  黄月英  战报21次  1.8万 10-18 20:21
01:11:42  曹彰/关羽/徐晃 11红  某某甲  荀彧    战报62次  1.3万 10-18 20:19
01:12:57  庞统/程昱/刘备 10红  某某甲  关银屏  战报57次  2.7万 10-19 20:45
```

手机横幅（一行一支敌军）：

```
某某甲 曹纯/张辽/文鸯 11红，推荐黄月英队
某某甲 曹彰/关羽/徐晃 11红，推荐荀彧队
某某甲 庞统/程昱/刘备 10红，推荐关银屏队
```

- **来的是哪队**：这支部队在战报里出现过，就直接给出它的阵容和红度（“来源”写见过几次）。
  没出现过时，按同一玩家相符的部队（“像他另一队”），或者按兵种从以往战报里推测（“推测”）。
- **派谁去接**：从你进阶过的部队里，推荐本赛季打这种阵容交换比最高、且大于 1 的一队（写大营武将），没有就写“无”；
  赶不赶得到、兵力和体力由你自己判断。
- **最近兵力**：这支敌军最近一场战报打完剩下的兵力加伤兵，和那场的时间。
- 看过的战报越多，阵容识别和推荐就越准。

其他通知：

| 通知 | 什么时候 |
|---|---|
| 盟友遇袭 | 敌军打盟友的地块，而你有部队来得及支援 |
| 领地 | 你的主城、要塞、城池被拆或失守 |
| 战斗 | 防守战斗的结果、进攻失败；打的是推荐里的第几名 |
| 阵容变化 | 某支敌军换了武将，列出原阵容和新阵容 |
| 部队 | 部队体力恢复，可以出征了 |
| 资源 | 木、铁、石、粮或政令快满仓了 |
| 同盟标记 | 同盟新增或取消标记 |
| 驻守 | 在游戏里点开一个地方，那里驻守的每支敌军和它的阵容；同一个地方只有驻守的部队变了才再通知 |
| 每日摘要 | 前一天的对战场数、胜负、交换比、敌袭次数、失守的据点 |

窗口里按 紧急 / 提醒 / 消息 分类，紧急通知会响铃，也可以弹出桌面弹窗；手机推送只发需要你马上处理的（如敌袭）。
通知过时了会自己清掉（比如敌袭在敌军到达时），窗口列表、桌面弹窗和手机推送都一样。

想少收一些？在窗口的**通知设置**里自己定，每一项下面都写了是什么意思，对这台电脑上的所有账号生效：

- **提醒方式**：被动（全部敌情都提醒），或主动（只提醒你在游戏里点开的地块）。
- **过滤斯巴达队伍**（默认关）：每名武将只带 100 兵左右的占位队伍不提醒。
- **过滤拆迁队伍**（默认关）：兵种都没进阶、兵力超过 300 的拆迁队伍不提醒。
- **盟友遇袭**：你能帮上忙时提醒 / 只在你有部队守着时提醒 / 不提醒。
- **推送到手机**：只推需要你下令的 / 所有敌情 / 不推送。
- 战斗结果、部队体力、资源、同盟标记、每日战况等可以分别关掉。
窗口里还能查玩家：

- **玩家信息**：输入玩家名字（可以只输一部分），同名或名字相近的有好几个时选一个。先列出他的同盟和主城坐标，
  再列出他每支队伍最近一次的武将、等级、红度、兵种和战法（只列兵种进阶过的队伍），我方、敌方都能查。
  只能查到本赛季同盟战报和你看过的部队详情里出现过的玩家；主城坐标要镜头在地图上见过这名玩家才知道。

还能和其他玩家聊天：

- **群聊**：所有开着率土战局的人在同一个群里，左侧点“群聊”就能发消息。每个人有一个固定的随机名字（比如“沉稳的赤兔”），
  看不出是谁。聊天记录只存在你自己的电脑上；程序没开的时候别人发的消息收不到。账号审核通过后才能用。

另外还有**战局网站**，在浏览器或手机上查看整个同盟的战报、阵容对局和攻城记录。

## 开始使用（Windows）

谁都可以用下面的公共域邀请码加入（加入私有域见[申请自己的域](#申请自己的域)）：

```
stj_6_P0QPrwxPEFsXNapoHCMA
```

1. 先装 [Wireshark](https://www.wireshark.org/download.html)（选 “Windows x64 Installer”），安装时保持勾选 Npcap，装完重启一次电脑。
2. 从 [Releases](https://github.com/nzery/stzb-warroom/releases/latest) 下载 `stzb-warroom-windows.zip`，解压到一个固定的文件夹。
3. 双击 `stzb-warroom.exe`，打开“率土战局”窗口。
4. 在“账号与推送”里粘贴邀请码（私有域用同盟发的 `stj_` 邀请码或管理员给的 `sta_` Token），点“添加”。在这台电脑上玩几个游戏账号，就加几次（一次加一个，加好后先登录那个账号）。
5. 登录游戏，角色认领成功后自动开始，“概览”里显示“正在上报”就说明一切正常。
6. 账号下面会出现“战局网站”，点“打开”就能在浏览器里看战局，也可以“复制链接”发到手机上打开。
7. 想在手机上收到推送：
   - iPhone：安装 Bark，把 Bark 里的地址粘贴到账号下面，点“绑定”，收到测试通知就成功了。
   - 安卓：安装 ntfy（F-Droid 或 Google Play），在账号下面点“绑定安卓”，用手机扫出现的二维码订阅，再点“发测试推送”。要给 ntfy 开自启动、电池设为不限制，否则锁屏后会被系统关掉。
8. 到“通知设置”里按自己的需要选择要哪些通知。
9. **第一次连上后同步同盟战报**：在游戏里打开 同盟 → 同盟战报，一直往下滑到底，滑过的战报会自动上传。
   敌军阵容是从同盟战报里认的，战报太少时很多认不出；同一个同盟里有人同步过，大家都能用上。
   同盟战报不到 2000 场时，窗口和推送会提醒你，并显示已同步的场数，够了就不再提醒。

公共域谁都可以加入，不限同盟和服务器，所有成员上传的战报、阵容对局、攻城记录汇总在一起，大家都能在战局网站上看到；
敌袭等通知只发给你自己。一个角色只能被一个人认领，先到先得；加入后 3 天内没登录游戏认领，邀请就会失效，要重新添加。

窗口里还有：

- **设置**：开机自动启动、关掉窗口后继续在后台运行（默认开启）；退出程序请右键托盘图标，选择“退出”。
- **诊断**：遇到问题时点“复制诊断信息”发给管理员。

下次打开自动开始。更详细的说明见压缩包里的 `使用说明.txt`。

## 用手机玩

手机上的游戏连接经你这台电脑出去：游戏看到的是你家里的网络，这台电脑照常上报，和在电脑上玩一样。
不用自己搭代理或 VPN，这台电脑也不开任何端口。

需要：

- 手机玩的时候，这台电脑开着、本程序在运行并且在上报。
- 账号已审核通过：先在这台电脑上登录一次游戏、认领角色（公共域也一样）。没审核通过的账号不能用手机玩。
- iPhone 上装小火箭（Shadowrocket），App Store 要用外区账号才能下载。
- 安卓上装 [v2rayNG](https://github.com/2dust/v2rayNG/releases)（免费，下载最新版 apk，一般选 `arm64-v8a`）。

iPhone 的步骤：

1. 窗口左侧点 **用手机玩**，打开“允许手机经本机连接游戏”。
2. 用小火箭首页左上角的扫码，扫页面上 **iPhone** 下面的二维码，添加节点。
3. 在小火箭的配置里加页面上给出的那条规则（形如 `DST-PORT,8001,节点名`），放在 `GEOIP`、`FINAL` 等规则前面。
   只让这一条走这个节点，别的流量不要走它（它只转游戏的连接，别的会连不上）。
4. 不要配置包含 DIRECT 的“故障转移”策略组；已按旧说明配置过的，把游戏规则改回直接指向页面上的节点。
   这样连接出问题时能及时发现，避免游戏照玩却没有上报。
5. 登录游戏，页面上的节点显示“已连接”、出现“正在转发 1 条游戏连接”就成功了。

安卓的步骤：

1. 同上，打开“允许手机经本机连接游戏”。
2. 打开 v2rayNG，点右上角的扫码图标扫页面上 **安卓** 下面的二维码（或者复制订阅地址发到手机，在 v2rayNG 菜单 → 订阅分组设置里添加）。
3. 菜单 → 更新当前组订阅，选中出现的节点，点右下角的启动按钮。规则都在订阅里，不用自己设置；
   只有游戏的连接经这台电脑，别的应用照常直连。
4. 登录游戏，和 iPhone 一样看页面上的“正在转发”。

已导入旧订阅的安卓用户：先“更新当前组订阅”，再停止并重新启动 v2rayNG 的 VPN。

要注意：

- 电脑关机或本程序没运行时，游戏连不上，不会自动切回直连。先打开电脑和本程序再玩；
  安卓临时想直连玩，可在 v2rayNG 里点停止，此时不上报。
- 二维码和订阅地址就是钥匙，别发给别人：拿到的人能借你的电脑连游戏。外泄了就在页面上点“重置”，旧的 30 秒内失效，手机重新扫码。
- 这台电脑只按中转的要求连游戏服务器的 8001 端口、只连公网地址，并且只在手机发的确实是游戏数据时保持连接；
  局域网、本机、别的端口一概不连。这部分代码在 `stzb_warroom/relay.py`，可以自己看。
- 手机的游戏连接经服务器中转。中转只转发，不记录、不保存游戏内容；上报仍由这台电脑完成。

## Linux / 命令行

需要 Python 3.11+ 和 `wireshark-common`（让普通用户有权限：`sudo dpkg-reconfigure wireshark-common`，再把自己加入 `wireshark` 组）。

```sh
export ST_SERVER=https://...                 # 服务器地址找管理员要
python3 -m stzb_warroom join stj_...         # 用邀请码加入
python3 -m stzb_warroom gui                  # 和 Windows 一样的窗口；也可以用 capture（只上报）+ notify（终端里看通知）
```

窗口用 [Electron](https://www.electronjs.org/) 显示：装了 `electron` 命令（如 `npm install -g electron`），或用环境变量 `ST_ELECTRON` 指向它；都没有时在默认浏览器里打开。

开机自动运行：`deploy/client-services.sh install`，用法见脚本开头。
用手机玩（同上，账号要先审核通过）：`deploy/client-services.sh install-phone`，再按上面的步骤在手机上设置；
二维码和链接用 `python3 -m stzb_warroom gui` 打开窗口查看。

## 遇到问题

- 窗口顶部的红色提示条会说明问题和处理办法，按提示操作即可。
- 官网打不开、连不上服务器：多半是开着代理、VPN 或加速器。服务器已屏蔽国外 IP，关掉它们或把 `nzery.dev` 设为直连再试。
- 加入后一直没开始：确认已经登录过游戏；提示角色已被别人认领时，发邮件给管理员核实。
- 其他问题：把“诊断”页的诊断信息发给管理员。

## 申请自己的域

想要只有你们同盟自己看得到的私有域，由同盟管理员发邮件到 <admin@nzery.dev> 找管理员申请域账号，邮件里附上游戏内的内政和同盟截图。服务器容量有限，先到先得。
