运行

开机自动启动

登录 Windows 后自动在后台开始上报，不弹窗口；这样启动时，关掉窗口也不会停。

关闭窗口后继续在后台运行

默认开启，关掉窗口也不停止上报。点击托盘图标可重新打开窗口，右键选择“退出”可关闭程序。
